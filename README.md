# TodoMate AI

TodoMate AI adalah aplikasi pengelola tugas (*to-do list*) berbasis Artificial Intelligence (AI) yang memungkinkan pengguna mengelola aktivitas sehari-hari melalui percakapan dalam Bahasa Indonesia.

Aplikasi ini menggunakan model Gemini AI untuk memahami instruksi pengguna dan menjalankan berbagai operasi pengelolaan tugas secara otomatis. Dengan antarmuka berbasis Streamlit, pengguna dapat menambahkan, melihat, mencari, memperbarui, menyelesaikan, dan menghapus tugas dengan mudah.

Proyek ini dikembangkan sebagai implementasi integrasi Large Language Model (LLM), AI Agent, database, dan aplikasi web interaktif.

### ✨ Fitur

* Menambahkan, melihat, mencari, mengubah, dan menghapus tugas.
* Menandai tugas sebagai selesai atau belum selesai.
* Mengelola tenggat waktu tugas.
* Berinteraksi dengan AI menggunakan bahasa alami.

### 🛠️ Teknologi

* Python
* Google Gemini AI
* LangChain & LangGraph
* Streamlit
* SQLite


### 🎯 Tujuan

Proyek ini bertujuan untuk mempelajari dan menerapkan:

* Integrasi Large Language Model (LLM) dengan aplikasi nyata.
* Pengembangan AI agent menggunakan LangGraph dan LangChain.
* Pemanggilan tools berdasarkan instruksi bahasa alami.
* Pengelolaan data menggunakan database SQLite.
* Pembuatan aplikasi web interaktif menggunakan Streamlit.
* Pengelolaan API key dan integrasi layanan AI eksternal.
